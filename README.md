# RomantasyCon Los Angeles

A fantasy-romance themed event website created for **RomantasyCon Los Angeles**, a real romantasy book convention. The website was developed as a front-end web development project using HTML, CSS, and JavaScript.

The site is designed to give attendees an immersive way to explore the convention, discover authors and activities, learn about the venue, and RSVP for the event.

##  Features

###  Event Information

* Event overview and description
* Convention schedule with individual event cards
* Featured attending authors
* Venue information
* Convention map
* Frequently asked questions
* Giveaway information

###  Interactive RSVP

The website includes an interactive RSVP form where visitors can enter:

* Name
* Location they're traveling from
* Their role at the convention
* Favorite attending author
* Whether they have attended before

The role selector includes options such as author, narrator, publisher, vendor, book-lover, volunteer, and more.

RSVP submissions are displayed through an **"Enchanted Guest Ledger"** and the site keeps track of the number of RSVPs.

###  Interactive & Visual Features

* Dark mode toggle
* Animated/revealable sections
* Interactive navigation
* Custom event cards
* Convention highlights photo gallery
* RSVP confirmation
* Success modal with themed imagery
* Fantasy-inspired typography and visual design

###  Convention Content

The website features information about activities including:

* Writing Seminar Panel
* Jewelry Making Workshop
* Fantasy Ball
* Sword Fighting Demonstration
* Fantasy Tea Party
* Character Cosplay Contest

The event also includes author profiles, venue details, giveaways, and convention highlights.

##  Technologies

* **HTML5** — structure and content
* **CSS3** — styling, layout, typography, and visual design
* **JavaScript** — interactivity, RSVP functionality, dark mode, animations, and modal behavior
* **Google Fonts** — Cinzel and Cormorant Garamond
* **VS Code for Education** — development environment

##  Design

The website uses a fantasy-inspired visual theme designed to match the romantasy genre. The design incorporates custom imagery, decorative dividers, fantasy-themed typography, event cards, and themed interactive elements.
